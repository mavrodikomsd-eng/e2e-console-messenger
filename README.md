# My Messenger

Простой консольный мессенджер на Python с **end-to-end шифрованием AES-128**.

## 🔐 Особенности

✅ **Консольный интерфейс** - простой и быстрый  
✅ **End-to-End шифрование (AES-128)** - сервер не видит содержимое сообщений  
✅ **Общий чат** для всех пользователей  
✅ **История сообщений** - все сообщения сохраняются в `messages.txt`  
✅ **Команды** - `/users`, `/clear`, `/help`, `/exit`  
✅ **Многопоточный сервер** - поддерживает несколько клиентов одновременно  

## 🛠️ Требования

- Python 3.6+
- pycryptodome (для AES шифрования)

## 📦 Установка

1. **Клонируй репозиторий:**
```bash
git clone https://github.com/yourusername/my-messenger.git
cd my-messenger
```

2. **Установи зависимости:**
```bash
pip install -r requirements.txt
```

3. **Готово!**

## 🚀 Запуск

### Сервер

```bash
python server.py
```

Сервер запустится на `localhost:1301`

### Клиент (открой новый терминал)

```bash
python client.py
```

Введи своё имя и начни писать сообщения!

### Несколько клиентов

Открой столько терминалов сколько нужно и запусти `python client.py` в каждом.

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/users` | Показать список онлайн пользователей |
| `/clear` | Очистить экран |
| `/help` | Показать справку по командам |
| `/exit` | Выход из чата |

## 🔒 Как работает шифрование

1. **Клиент** пишет сообщение
2. **Клиент** шифрует его (AES-128, ключ: `mysecretkey12345`)
3. **Клиент** отправляет только шифрованный текст на сервер
4. **Сервер** видит только зашифрованные данные (не может прочитать)
5. **Сервер** передаёт шифр другим клиентам
6. **Клиент** получает шифр и расшифровывает (знает ключ)
7. **Клиент** показывает открытое сообщение пользователю

**Результат:** сервер полностью слеп к содержимому сообщений! 🔐

## 🔧 Изменение ключа шифрования

Если хочешь изменить ключ шифрования:

1. Открой `crypto.py`
2. Найди строку: `SHARED_KEY = b"mysecretkey12345"`
3. Замени на свой ключ (ровно 16 символов)

**Пример:**
```python
SHARED_KEY = b"mysupertopsecret"
```

## 📊 История сообщений

Все сообщения автоматически сохраняются в `messages.txt`:

```
[2024-12-19 14:30:45] Alice: Привет!
[2024-12-19 14:30:52] Bob: Привет, Alice!
[2024-12-19 14:31:00] Alice: Как дела?
```

История сохраняется в **открытом виде** (для удобства просмотра).


## ⚙️ Технический стек

- **Язык:** Python 3.6+
- **Сеть:** TCP сокеты
- **Многопоточность:** threading
- **Криптография:** AES-128 (pycryptodome)
- **База данных:** текстовый файл (messages.txt)

## 🐛 Известные проблемы

- Максимум 5 одновременных подключений (можно увеличить в коде)
- История не загружается при подключении (только новые сообщения)
- Нет аутентификации (каждый может быть кем угодно)
- Шифрование одинаковое для всех (нет приватных DM)

## 🔐 Безопасность

⚠️ **ВАЖНО:** Это **образовательный проект**!

Используется для обучения концепциям:
- ✅ TCP сокеты
- ✅ Многопоточность

- TLS/SSL (защита канала)
- Rate limiting (защита от спама)
