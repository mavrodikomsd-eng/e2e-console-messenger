## ✨ Особенности проекта

- 🔐 **E2E Шифрование**: Используется криптостойкий алгоритм **AES-256-GCM** (с контролем целостности и аутентификацией данных).
- 🐍 **Python & 🚀 Go**: Поддержка реализации бэкенда как на Python (`server.py`), так и высокопроизводительного сервера на Go (`server.go`).
- 💻 **Два варианта клиента**: Консольный интерфейс (`client.py`) и графический GUI интерфейс (`client_gui.py`).
- 🎛️ **Удобные команды**: Поддержка встроенных команд (`/users`, `/help`, `/clear`, `/exit`).
- 📝 **Логирование**: Сохранение истории сообщений.
- 🌐 **UTF-8**: Полная поддержка русского языка и эмодзи.

## 🏗️ Архитектура и структура файлов

Проект имеет чистую модульную структуру:

```text
per12re/
├── 📄 server.py            # Серверная часть (Python, многопоточная)
├── 📄 server.go            # Серверная часть (Go, высокопроизводительная)
├── 📄 client.py            # Консольный клиент мессенджера
├── 📄 client_gui.py        # Графический клиент (GUI)
├── 📄 config.json          # Конфигурация Python-клиента/сервера
├── 📄 configs.json         # Конфигурация Go-сервера
├── 📄 requirements.txt     # Python зависимости
└── 📁 modules/             # Внутренние модули
    ├── 📄 crypto.py        # AES-256-GCM шифрование
    ├── 📄 protocol.py      # Сетевой протокол обмена
    ├── 📄 config.py        # Загрузчик настроек
    ├── 📄 commands.py      # Обработчик слэш-команд
    └── 📄 ui.py            # Оформление интерфейса и баннеры
```

### Таблица компонентов

| Файл / Модуль | Описание |
| :--- | :--- |
| **`server.py` / `server.go`** | Многопоточные серверные реализации (трансляция зашифрованного трафика) |
| **`client.py`** | Консольный клиент чата с потоками приема и отправки |
| **`client_gui.py`** | Графический интерфейс клиента (GUI на Tkinter/CustomTkinter) |
| **`modules/crypto.py`** | Криптографический модуль на базе `pycryptodome` |
| **`modules/protocol.py`** | Протокол сериализации и передачи пакетов |

## 🚀 Руководство по запуску

### 1. Запуск сервера (на выбор)
* **Python-сервер:**
  ```bash
  python server.py
  ```
* **Go-сервер:**
  ```bash
  go run server.go
  ```

### 2. Запуск клиента
Подключитесь к запущенному серверу с помощью консольного или графического клиента:

* **Консольный клиент:**
  ```bash
  python client.py
  ```
* **Графический клиент (GUI):**
  ```bash
  python client_gui.py
  ```

## 🔐 Безопасность

- **Ключ хранится в отдельном файле `secret.key`** и **никогда не попадает в git**
  (файл добавлен в `.gitignore`). В `config.json` / `configs.json` секретов нет.
- Ключ **генерируется автоматически при первом запуске** любого компонента.
  Если у тебя была старая версия с ключом внутри конфига — он будет
  автоматически перенесён в `secret.key` при первом запуске.
- Чтобы поделиться ключом с участниками чата — все должны использовать
  **один и тот же `secret.key`**. Скопируй файл или сгенерируй ключ вручную:
  ```bash
  openssl rand -base64 32   # → вставь результат в secret.key
  ```
- **Подпись отправителя (AAD):** имя отправителя привязывается к шифротексту
  через Additional Authenticated Data (AES-GCM). Если имя в кадре подменили —
  получатель увидит «не удалось расшифровать».
  *Важно:* при общем ключе активный злоумышленник всё ещё может прислать
  сообщение «от чужого имени», подписав его своим ключом. Полноценная защита
  от этого требует парных ключей между клиентами (обмен X25519) — это следующее
  крупное улучшение проекта.
