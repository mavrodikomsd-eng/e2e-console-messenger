# Web Interface — Не используется в основном проекте

Этот каталог содержит веб-клиент для MeshMessenger, который был добавлен в demonstrative целях.

**Что содержится:**
- `server_web.py` — Flask-сервер с WebSocket поддержкой
- `templates/index.html` — HTML страница чата
- `static/style.css` — Стили (темная тема)
- `static/app.js` — Логика подключения

**Зачем тут это есть:**
Была попытка добавить веб-интерфейс, но решено оставить только консольный и Go-клиенты. Этот каталог можно полностью удалить, если он не нужен.

**Как удалить (если нужно):**
1. Удалить папку `web/`
2. Удалить запись `web/` из `.gitignore` (если когда-то понадобится вернуться)

**Статус:** Не используется в текущей версии проекта. Основные клиенты: `client.py` (консоль) и `server.go` (Go сервер).
