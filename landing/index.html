Развернуть за 3 шага

# 1. Клонировать
git clone https://github.com/your-repo/mesh-messenger.git
cd mesh-messenger

# 2. Запустить
docker compose up -d

# 3. Готово!
Сервер: your-server:1301
Админка: http://your-server:8080

Что внутри

💻 Сервер (Go)

Высокая производительность, низкое потребление памяти. Обрабатывает тысячи подключений.

💻 GUI-клиент (Rust + egui)

Telegram-style интерфейс. Windows, Linux, macOS. Красивый и быстрый.

📊 Админ-панель

Управление пользователями, статистика, блокировка. Всё через веб.

🔒 E2E шифрование

Сервер не видит содержимое сообщений. Только маршрутизация.
